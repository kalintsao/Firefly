# Lua 快速入门教程

## 一、环境搭建

对于有编程基础的开发者，推荐直接安装 Lua 5.4 版本。在 macOS 上可通过 `brew install lua` 安装；在 Ubuntu/Debian 上执行 `sudo apt install lua5.4`；Windows 用户可通过 LuaBinaries 下载预编译的二进制文件，或使用包管理器如 Scoop (`scoop install lua`)。

安装完成后，在终端输入 `lua` 即可进入交互式 REPL 环境。验证安装是否成功，运行以下代码：

```lua
print("Hello, Lua!")
```

## 二、基本语法

### 2.1 注释

Lua 使用 `--` 进行单行注释，使用 `--[[ ... ]]` 进行多行注释。

```lua
-- 这是单行注释

--[[
    这是多行注释
    可以跨越多行
]]
```

### 2.2 变量与类型

Lua 中变量默认是全局的，强烈建议使用 `local` 关键字声明局部变量以提升性能并避免命名污染。未赋值的变量值为 `nil`。

Lua 是动态类型语言，包含八种基本类型：`nil`, `boolean`, `number`, `string`, `table`, `function`, `thread`, `userdata`。

```lua
local x = 10          -- number 类型
local name = "Lua"    -- string 类型
local flag = true     -- boolean 类型
local t = {}          -- table 类型

print(type(x))        -- 输出: number
print(type(nil_var))  -- 输出: nil
```

### 2.3 运算符

Lua 支持常规的算术运算符（`+`, `-`, `*`, `/`, `%`, `^`, `//`）和关系运算符（`==`, `~=`, `<`, `>`, `<=`, `>=`）。**注意**：在 Lua 中，`0` 和空字符串 `""` 在条件判断中均为 `true`，只有 `false` 和 `nil` 为 `false`。

逻辑运算符 `and`, `or`, `not` 具有短路求值特性，且 `and` 和 `or` 会返回导致决定结果的操作数本身，而非单纯的布尔值。字符串拼接使用 `..` 运算符。

```lua
local a, b = 5, 10
print(a + b)          -- 15
print(a ~= b)         -- true
print(a > 0 and "正数" or "非正数") -- "正数"
print("Hello" .. " " .. "World")    -- "Hello World"
```

### 2.4 控制结构

Lua 的控制结构包括 `if/elseif/else`、`while/do...end`、`repeat...until`（后测试循环，注意条件是直到为真时退出）以及 `for` 循环。

```lua
-- if 判断
if score >= 90 then
    print("优秀")
elseif score >= 60 then
    print("及格")
else
    print("不及格")
end

-- 数值 for 循环 (从1到10，步长为2)
for i = 1, 10, 2 do
    print(i)
end

-- repeat...until 循环
local count = 0
repeat
    count = count + 1
until count >= 5
```

## 三、函数

Lua 中的函数是一等公民，支持多返回值、可变参数以及作为匿名函数（闭包）使用。

```lua
-- 多返回值
local function swap(a, b)
    return b, a
end
local x, y = swap(1, 2) -- x=2, y=1

-- 可变参数
local function sum(...)
    local args = {...}
    local total = 0
    for _, v in ipairs(args) do total = total + v end
    return total
end

-- 匿名函数与闭包
local function counter()
    local n = 0
    return function() n = n + 1; return n end
end
local c = counter()
print(c()) -- 1
```

## 四、Table（核心数据结构）

Table 是 Lua 中唯一的复杂数据结构，它既是数组又是字典（关联数组）。**注意**：Lua 的数组索引默认从 `1` 开始。

```lua
-- 字典用法
local user = {name = "Alice", age = 25}
print(user.name)      -- "Alice"

-- 数组用法
local arr = {"a", "b", "c"}
print(arr[1])         -- "a"

-- 常用表操作
table.insert(arr, "d")
table.sort(arr)
print(table.concat(arr, ", ")) -- "a, b, c, d"

-- 迭代器区别
-- pairs() 遍历所有键值对（无序，包含非数字键）
-- ipairs() 仅遍历从1开始的连续整数键（有序数组）
for k, v in pairs(user) do print(k, v) end
```

## 五、模块与包

Lua 没有内置的模块关键字，通常使用 table 来模拟模块，并通过 `require` 机制加载。

```lua
-- mymath.lua
local M = {}
function M.add(a, b) return a + b end
return M

-- main.lua
local mymath = require("mymath")
print(mymath.add(1, 2)) -- 3
```

`require` 会缓存已加载的模块，多次调用只会执行一次模块代码。

## 六、元表与元方法

元表（Metatable）允许改变 table 的行为。通过 `setmetatable` 设置，通过 `getmetatable` 获取。常用的元方法包括 `__add`（加法）、`__index`（查找缺失键）、`__tostring`（字符串转换）。

```lua
local mt = {
    __add = function(a, b)
        return {x = a.x + b.x, y = a.y + b.y}
    end,
    __tostring = function(t)
        return string.format("(%d, %d)", t.x, t.y)
    end
}

local v1 = setmetatable({x=1, y=2}, mt)
local v2 = setmetatable({x=3, y=4}, mt)
print(v1 + v2) -- 输出: (4, 6)
```

## 七、常用标准库速查

Lua 提供了丰富的标准库，以下是高频使用的函数示例：

```lua
-- string 库
string.gsub("hello world", "l", "L")     -- "heLLo worLd"
string.match("2024-01-01", "%d+")        -- "2024"
string.format("Pi: %.2f", 3.14159)       -- "Pi: 3.14"

-- math 库
math.floor(3.7)                          -- 3
math.random(1, 100)                      -- 1~100随机数

-- os 库
os.time()                                -- 当前时间戳
os.date("%Y-%m-%d", os.time())           -- "2026-09-07"

-- io 库
local f = io.open("test.txt", "r")
local content = f:read("*a")             -- 读取全部内容
f:close()
```

## 八、实战示例

以下是一个读取文本文件并统计单词出现频率的完整示例，综合运用了文件 IO、字符串处理、table 和排序：

```lua
local function word_count(filename)
    local f = io.open(filename, "r")
    if not f then return nil, "File not found" end

    local counts = {}
    for line in f:lines() do
        for word in line:gmatch("%w+") do
            word = word:lower()
            counts[word] = (counts[word] or 0) + 1
        end
    end
    f:close()
    return counts
end

local result, err = word_count("article.txt")
if not result then print(err); return end

-- 转换为数组以便排序
local list = {}
for k, v in pairs(result) do
    table.insert(list, {word = k, count = v})
end

table.sort(list, function(a, b) return a.count > b.count end)

for i = 1, 10 do
    local item = list[i]
    if not item then break end
    print(string.format("%-15s %d", item.word, item.count))
end
```
